19:T2d5b,<h1 id="getting-started">Getting started</h1>
<h2 id="requirements"><a class="heading-anchor" href="#requirements">Requirements</a></h2>
<ul>
<li><strong>Go 1.24</strong> or later, with cgo.</li>
<li><strong>A C compiler</strong>: gcc or clang on Linux and macOS; on Windows MinGW gcc, or
<a href="https://ziglang.org/download/" target="_blank" rel="noreferrer noopener">zig</a> (<code>napi-go build -zig always</code>).</li>
<li><strong>Node.js 22</strong> or later.</li>
<li>Optional: <strong>zig</strong>, to build for other platforms (<code>napi-go build -target …</code>) and to make Linux
release binaries that run on older distributions (glibc 2.17).</li>
</ul>
<h2 id="create-a-project"><a class="heading-anchor" href="#create-a-project">Create a project</a></h2>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#6F42C1;--shiki-dark:#B392F0">go</span><span style="color:#032F62;--shiki-dark:#9ECBFF"> run</span><span style="color:#032F62;--shiki-dark:#9ECBFF"> github.com/napi-bindings/napi-go/cmd/napi-go@latest</span><span style="color:#032F62;--shiki-dark:#9ECBFF"> new</span><span style="color:#032F62;--shiki-dark:#9ECBFF"> my-addon</span></span>

<span class="line"><span style="color:#6F42C1;--shiki-dark:#B392F0">npm</span><span style="color:#032F62;--shiki-dark:#9ECBFF"> run</span><span style="color:#032F62;--shiki-dark:#9ECBFF"> build:debug</span></span>
<span class="line"><span style="color:#6F42C1;--shiki-dark:#B392F0">npm</span><span style="color:#032F62;--shiki-dark:#9ECBFF"> test</span></span></code></pre>

<p>Builds for another platform use zig as C compiler. The targets are <code>linux-x64-gnu</code>,
<code>linux-arm64-gnu</code>, <code>darwin-x64</code>, <code>darwin-arm64</code>, <code>win32-x64-gnu</code> and <code>win32-arm64-gnu</code>; see the
<a href="/projects/napi-go/docs/cmd/napi-go/#targets">CLI reference</a>.</p>
<h2 id="publish"><a class="heading-anchor" href="#publish">Publish</a></h2>
<p>The package follows the layout of napi-rs: the main package holds <code>index.js</code> and <code>index.d.ts</code>, and
each target has a package <code>my-addon-&#x3C;target></code> with its <code>.node</code> file, installed by npm only on
matching machines.</p>
<p>The workflow created by <code>new</code> does it all: push a tag <code>v&#x3C;version></code> equal to the version of
<code>package.json</code>, with the repository secret <code>NPM_TOKEN</code>. By hand:</p>
