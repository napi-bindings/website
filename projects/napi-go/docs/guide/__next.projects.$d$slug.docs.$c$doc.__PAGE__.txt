19:Ta224,<h1 id="writing-addons">Writing addons</h1>
<p>An addon is a Go <code>main</code> package built with <code>-buildmode=c-shared</code>. The usual way to write one is
to annotate Go declarations and let <code>napi-go gen</code> generate the registrations (Layer 2). This
guide shows the common cases; the <a href="/projects/napi-go/docs/napi/"><code>napi</code> reference</a> and the
<a href="/projects/napi-go/docs/internal/codegen/">annotation reference</a> have the details.</p>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">package</span><span style="color:#6F42C1;--shiki-dark:#B392F0"> main</span></span>
<span class="line"></span>
<span class="line"><span style="color:#6A737D;--shiki-dark:#6A737D">//go:generate go tool napi-go gen</span></span>
<span class="line"></span>
<span class="line"><span style="color:#6A737D;--shiki-dark:#6A737D">// Add returns a + b.</span></span>
<span class="line"><span style="color:#6A737D;--shiki-dark:#6A737D">//</span></span>
<span class="line"><span style="color:#6A737D;--shiki-dark:#6A737D">//napi:export</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">func</span><span style="color:#6F42C1;--shiki-dark:#B392F0"> Add</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(</span><span style="color:#E36209;--shiki-dark:#FFAB70">a</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#E36209;--shiki-dark:#FFAB70">b</span><span style="color:#D73A49;--shiki-dark:#F97583"> float64</span><span style="color:#24292E;--shiki-dark:#E1E4E8">) </span><span style="color:#D73A49;--shiki-dark:#F97583">float64</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> { </span><span style="color:#D73A49;--shiki-dark:#F97583">return</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> a </span><span style="color:#D73A49;--shiki-dark:#F97583">+</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> b }</span></span>

<h2 id="functions"><a class="heading-anchor" href="#functions">Functions</a></h2>
<p><code>//napi:export</code> exports a function under its Go name in lowerCamelCase (<code>ParseURL</code> →
<code>parseURL</code>), or under the name that follows the annotation (<code>//napi:export parse</code>). Functions
take up to 8 JS parameters and return nothing, a value, an error, or a value and an error.</p>
<p>A parameter of type <code>napi.Env</code> or <code>napi.CallContext</code> is filled from the call and takes no JS
argument: use it to create JS values or read <code>this</code> and the raw arguments. A missing JS argument
is <code>undefined</code>; extra arguments are ignored.</p>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#6A737D;--shiki-dark:#6A737D">//napi:export</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">func</span><span style="color:#6F42C1;--shiki-dark:#B392F0"> Lines</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(</span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#6F42C1;--shiki-dark:#B392F0"> napi</span><span style="color:#24292E;--shiki-dark:#E1E4E8">.</span><span style="color:#6F42C1;--shiki-dark:#B392F0">Env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#E36209;--shiki-dark:#FFAB70">text</span><span style="color:#D73A49;--shiki-dark:#F97583"> string</span><span style="color:#24292E;--shiki-dark:#E1E4E8">) (</span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi</span><span style="color:#24292E;--shiki-dark:#E1E4E8">.</span><span style="color:#6F42C1;--shiki-dark:#B392F0">Array</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">error</span><span style="color:#24292E;--shiki-dark:#E1E4E8">) { … }</span></span></code></pre>
<h2 id="types"><a class="heading-anchor" href="#types">Types</a></h2>
<p>Arguments are converted from their Go type, and checked: a wrong type throws a TypeError with
code <code>ERR_INVALID_ARG_TYPE</code> and the position of the value (<code>argument 1: tags[2]: expected string, got number</code>). Integers must be integers in range, never truncated.</p>

<h2 id="objects"><a class="heading-anchor" href="#objects">Objects</a></h2>
<p>Struct fields are named with their <code>napi</code> tag, else their <code>json</code> tag, else their Go name in
lowerCamelCase. <code>napi:"-"</code> skips a field; <code>omitempty</code>, a pointer, or <code>any</code> make it optional.</p>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">type</span><span style="color:#6F42C1;--shiki-dark:#B392F0"> User</span><span style="color:#D73A49;--shiki-dark:#F97583"> struct</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> {</span></span>

<p>A struct used by an exported function is declared in <code>index.d.ts</code> as an interface. Annotate it
with <code>//napi:object</code> to declare it even when no function uses it.</p>

<h2 id="async-functions"><a class="heading-anchor" href="#async-functions">Async functions</a></h2>
<p>A function whose first parameter is a <code>context.Context</code> returns a Promise. Its arguments are
converted on the JS thread (a wrong argument throws right away), it runs in a goroutine, and its
result is converted on the JS thread when it returns.</p>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#6A737D;--shiki-dark:#6A737D">// Fetch downloads url.</span></span>
<span class="line"><span style="color:#6A737D;--shiki-dark:#6A737D">//</span></span>
<span class="line"><span style="color:#6A737D;--shiki-dark:#6A737D">//napi:export</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">func</span><span style="color:#6F42C1;--shiki-dark:#B392F0"> Fetch</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(</span><span style="color:#E36209;--shiki-dark:#FFAB70">ctx</span><span style="color:#6F42C1;--shiki-dark:#B392F0"> context</span><span style="color:#24292E;--shiki-dark:#E1E4E8">.</span><span style="color:#6F42C1;--shiki-dark:#B392F0">Context</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#E36209;--shiki-dark:#FFAB70">url</span><span style="color:#D73A49;--shiki-dark:#F97583"> string</span><span style="color:#24292E;--shiki-dark:#E1E4E8">) ([]</span><span style="color:#D73A49;--shiki-dark:#F97583">byte</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">error</span><span style="color:#24292E;--shiki-dark:#E1E4E8">) {</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">	req, err </span><span style="color:#D73A49;--shiki-dark:#F97583">:=</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> http.</span><span style="color:#6F42C1;--shiki-dark:#B392F0">NewRequestWithContext</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(ctx, http.MethodGet, url, </span><span style="color:#005CC5;--shiki-dark:#79B8FF">nil</span><span style="color:#24292E;--shiki-dark:#E1E4E8">)</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">	if</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> err </span><span style="color:#D73A49;--shiki-dark:#F97583">!=</span><span style="color:#005CC5;--shiki-dark:#79B8FF"> nil</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> {</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">		return</span><span style="color:#005CC5;--shiki-dark:#79B8FF"> nil</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, err</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">	}</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">	resp, err </span><span style="color:#D73A49;--shiki-dark:#F97583">:=</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> http.DefaultClient.</span><span style="color:#6F42C1;--shiki-dark:#B392F0">Do</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(req)</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">	if</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> err </span><span style="color:#D73A49;--shiki-dark:#F97583">!=</span><span style="color:#005CC5;--shiki-dark:#79B8FF"> nil</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> {</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">		return</span><span style="color:#005CC5;--shiki-dark:#79B8FF"> nil</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, err</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">	}</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">	defer</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> resp.Body.</span><span style="color:#6F42C1;--shiki-dark:#B392F0">Close</span><span style="color:#24292E;--shiki-dark:#E1E4E8">()</span></span>

<li><code>ctx</code> is canceled when the env is destroyed: a worker thread terminated, or the process
exiting. Stop the work then; its result is dropped.</li>
<li>The parameters and the result must not contain napi values: they are only valid on the JS
thread. <code>[]byte</code> arguments are copied for the goroutine.</li>
<li>Node.js keeps running until the Promise settles.</li>
<li>Many Promises settled together cost little: napi-go wakes the JS thread once for a batch
(<a href="/projects/napi-go/docs/bench/">benchmarks</a>).</li>
</ul>

<li>Every exported method of <code>*T</code> is a method of the class, unless marked <code>//napi:skip</code>.
<code>//napi:export Counter.fromString</code> on a function makes a static method.</li>
<li>A <code>*T</code> parameter accepts only instances of the class; a <code>*T</code> result returns the instance that
wraps it, or creates one: in an env the same <code>*T</code> is always the same JS object.</li>
<li><code>func (c *T) Finalize(env napi.Env)</code> runs when the last instance wrapping the value is garbage
collected. It must not call JS.</li>
<li>JS classes can extend it (<code>class Sub extends Counter</code>).</li>
</ul>

<h2 id="threads-and-memory"><a class="heading-anchor" href="#threads-and-memory">Threads and memory</a></h2>
<ul>
<li><strong>napi values belong to the JS thread.</strong> <code>napi.Env</code>, <code>napi.Value</code> and the types built on them
must not be used in goroutines, and must not be kept after the call returns (to keep a JS value,
create a reference with <code>Value.NewRef</code>).</li>
<li><strong>A <code>[]byte</code> argument is a view of JS memory</strong>, valid during the call: copy it to keep it.</li>
<li><strong>Worker threads load the addon again</strong>, with their own env, but share the Go runtime and its
global variables: protect global state as for any concurrent Go code.</li>
<li>Go values reach JS only through napi-go, which follows the cgo pointer rules: no Go pointer is
handed to Node.js.</li>
</ul>
<h2 id="layer-1"><a class="heading-anchor" href="#layer-1">Layer 1</a></h2>

descriptors, references, handle scopes, external buffers, type tags), use the Layer 1 API in the
same addon: <code>napi.Init</code> registers a function that receives the env and the exports object, as in
node-addon-api.</p>
