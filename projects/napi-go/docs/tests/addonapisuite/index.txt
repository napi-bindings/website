39:T1ffc,<h1 id="node-addon-api-test-suite-ported-to-napi">node-addon-api Test Suite Ported to <code>napi</code></h1>
<p>The <a href="https://github.com/nodejs/node-addon-api" target="_blank" rel="noreferrer noopener">node-addon-api</a> tests for the parts of the C++ API
that Layer 1 (<code>napi</code>) covers, with the C++ test binding (<code>test/binding.cc</code> and the files it
includes) rewritten in Go on top of <code>napi</code>. The JS scripts are node-addon-api's own: when one
passes, the Go binding behaves like the C++ one, including error messages. The few lines changed
for napi-go are marked with a <code>// napi-go:</code> comment and listed below.</p>
<p>Source: nodejs/node-addon-api @ <code>25c6b21</code>. License of copied files:
<a href="https://github.com/napi-bindings/napi-go/blob/main/tests/addonapisuite/LICENSE.node-addon-api.md" target="_blank" rel="noreferrer noopener">LICENSE.node-addon-api.md</a> (MIT).</p>
