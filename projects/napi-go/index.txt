<ul>
<li><strong>Conversions from Go types</strong>: numbers, strings, <code>[]byte</code>, slices, maps, structs, pointers,
<code>*big.Int</code>, <code>time.Time</code>; wrong JS arguments throw a TypeError naming the argument.</li>
<li><strong>Goroutines</strong>: functions with a <code>context.Context</code> return Promises; goroutines call JS functions
with <code>JSFunc</code>; Promises settled in bulk cost one wake-up of the JS thread.</li>
<li><strong>Classes</strong> backed by Go values, with methods, getters, setters and finalizers.</li>
<li><strong>TypeScript declarations</strong> generated from the Go code, Go comments as JSDoc.</li>
<li><strong>One machine builds all platforms</strong>: Linux, macOS and Windows on x64 and arm64, with zig;
one npm package per platform, as napi-rs.</li>
<li><strong>Worker threads</strong>, Node-API 8 to 10, and the Node.js and node-addon-api test suites ported to
napi-go.</li>
</ul>

<h2 id="platforms"><a class="heading-anchor" href="#platforms">Platforms</a></h2>
<p>Linux (glibc) x64 and arm64, macOS arm64 and x64, Windows x64 and arm64, with Go 1.24 or later and
Node.js 22 or later. Not supported: musl (Alpine), which no Go release can load as a shared
library. On macOS x64, one Go addon per process. See <a href="/projects/napi-go/docs/platforms/">platforms</a>.</p>
