<h2 id="unreleased-version-1000"><a class="heading-anchor" href="#unreleased-version-1000">Unreleased Version 10.0.0</a></h2>
<h3 id="notable-changes"><a class="heading-anchor" href="#notable-changes">Notable changes</a></h3>
<ul>
<li>Updated to Node-API version 10. Headers and the <code>.def</code> files are vendored
unmodified from <code>node-api-headers</code> 1.9.0 (155 symbols); 9 symbols were missing
in 8.0.0.</li>
<li>New <code>NodeApi::NodeApi</code> CMake target that applies the right link mechanism for
each platform: import library for <code>NODE.EXE</code> with a delay-load hook on
Windows (MSVC and MinGW), <code>-U</code> for each Node-API symbol on macOS, nothing on
ELF platforms.</li>
<li>The project can be consumed with <code>FetchContent</code>, <code>add_subdirectory</code> and
<code>find_package(NodeApi)</code> (exported targets and package config files).</li>
<li>The stub source is generated from the <code>.def</code> file. Static and shared stub
libraries are optional and abort with a message when called, instead of
returning <code>napi_ok</code> with uninitialised results.</li>
<li>New tests that load the addons in Node.js, including the <code>-Bsymbolic</code> case.</li>
<li>New build matrix: Linux x64/arm64 (glibc and musl), macOS universal, Windows
x64/x86/arm64 (MSVC) and x64 (MinGW).</li>
</ul>
<h3 id="breaking-changes"><a class="heading-anchor" href="#breaking-changes">Breaking changes</a></h3>
<ul>
<li>Headers moved from the repository root to <code>include/</code>; <code>node_api.c</code> removed.</li>
<li>The <code>node_api</code> target and <code>libnode_api.a</code> are replaced by <code>NodeApi::NodeApi</code>
and, for the static stub, <code>NodeApi::stub</code> / <code>libnode_api_stub.a</code>
(<code>NodeApi::legacy</code> is an alias of it).</li>
</ul>
