19:T35e6,<h1 id="writing-tests">Writing Tests</h1>
<p>There are multiple flavors of node-addon-api test builds that cover different
build flags defined in <code>napi.h</code>:</p>
<ol>
<li>c++ exceptions enabled,</li>
<li>c++ exceptions disabled,</li>
<li>c++ exceptions disabled, and <code>NODE_ADDON_API_ENABLE_MAYBE</code> defined.</li>
</ol>
<p>Functions in node-addon-api that call into JavaScript can have different
declared return types to reflect build flavor settings. For example,
<code>Napi::Object::Set</code> returns <code>bool</code> when <code>NODE_ADDON_API_ENABLE_MAYBE</code>
is not defined, and <code>Napi::Maybe&#x3C;bool></code> when <code>NODE_ADDON_API_ENABLE_MAYBE</code>
is defined. In source code, return type variants are defined as
<code>Napi::MaybeOrValue&#x3C;></code> to prevent the duplication of most of the code base.</p>
<p>To properly test these build flavors, all values returned by a function defined
to return <code>Napi::MaybeOrValue&#x3C;></code> should be tested by using one of the following
test helpers to handle possible JavaScript exceptions.</p>
<p>There are three test helper functions to conveniently convert
<code>Napi::MaybeOrValue&#x3C;></code> values to raw values.</p>
<h2 id="maybeunwrap"><a class="heading-anchor" href="#maybeunwrap">MaybeUnwrap</a></h2>
