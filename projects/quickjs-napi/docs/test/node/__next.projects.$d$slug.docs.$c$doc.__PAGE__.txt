<p>The script also generates <code>&#x3C;suite>/tests.cmake</code> from each <code>binding.gyp</code>, so
the build needs neither Python nor node-gyp. CTest names the tests
<code>node/&#x3C;suite>/&#x3C;test>/&#x3C;script></code>.</p>
<p><code>common/</code> is ours (a minimal replacement of Node's <code>test/common</code> and of the
<code>assert</code> module, providing only what the enabled tests use, and
<code>require-as-module.js</code>), except <code>common/gc.js</code> and <code>common/tick.js</code>, copied
verbatim from Node.js by the script.</p>
<p>Every <code>.js</code> file of an enabled test directory is a test script, as in
Node.js, with the exceptions declared in the script.</p>
