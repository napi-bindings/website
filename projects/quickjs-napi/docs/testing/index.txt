<h2 id="sanitizers-and-leak-checks"><a class="heading-anchor" href="#sanitizers-and-leak-checks">Sanitizers and leak checks</a></h2>
<ul>
<li><strong>Debug builds</strong> use a Debug QuickJS, whose <code>JS_FreeRuntime</code> asserts that
every object was released. Any <code>JSValue</code> leaked by the library aborts the
test. This is why the library frees, at teardown, what addons never deleted.</li>
<li><strong><code>unix-asan</code></strong> runs everything under AddressSanitizer, UndefinedBehavior
Sanitizer and LeakSanitizer, QuickJS included. <code>test/lsan.supp</code> suppresses
the leaks that Node.js and node-addon-api tests make <strong>by design</strong> (each
entry says why).</li>
<li><strong><code>unix-tsan</code></strong> runs everything under ThreadSanitizer, QuickJS and libuv
included: async work and thread-safe functions are exercised from several
threads. CI reduces ASLR entropy for it.</li>
</ul>

<h2 id="workflows"><a class="heading-anchor" href="#workflows">Workflows</a></h2>
<h3 id="implementing-or-changing-a-node-api-function"><a class="heading-anchor" href="#implementing-or-changing-a-node-api-function">Implementing or changing a Node-API function</a></h3>
<ol>
<li>Implement it in the <code>src/</code> file of its area, following the Node.js source
(<code>src/js_native_api_v8.cc</code>, <code>src/node_api.cc</code>) for statuses and edge
cases. Use the macros of <code>qjsnapi_internal.h</code> (<code>NAPI_PREAMBLE</code>,
<code>CHECK_ARG</code>, <code>CHECK_JS</code>, ...) so the error behaviour matches.</li>
<li>Run <code>python3 tools/gen_stubs.py</code> to drop its stub; <code>stubs_up_to_date</code> fails
otherwise.</li>
<li>Enable the matching Node.js test in <code>tools/sync_node_tests.py</code> (<code>TESTS</code>) and
re-run it, or add a case to a <code>test/js</code> script and its addon.</li>
<li>Run the suite in Debug (leak assertion) and under <code>unix-asan</code>.</li>
<li>Update the reference page in <a href="/projects/quickjs-napi/docs/node-api/">doc/node-api</a> and, for a
deviation, <a href="/projects/quickjs-napi/docs/compatibility/">compatibility.md</a>.</li>
</ol>
<h3 id="adding-a-js-test"><a class="heading-anchor" href="#adding-a-js-test">Adding a JS test</a></h3>
<p>Write it so that it runs <strong>unchanged under both runtimes</strong> (see
<code>test/js/test_hello.js</code>): it receives the addon directory as an argument and
throws on the first failed expectation. Register it in <code>CMakeLists.txt</code>
next to the other <code>js_*</code> tests; the <code>node_parity_*</code> variant is added the same
way.</p>
