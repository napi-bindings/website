<h2 id="implementation-notes"><a class="heading-anchor" href="#implementation-notes">Implementation notes</a></h2>
<ul>
<li><strong>Type checks use class IDs.</strong> QuickJS does not export its class ID enum, so
the IDs of <code>ArrayBuffer</code>, <code>SharedArrayBuffer</code>, <code>DataView</code>, <code>Date</code> and the
typed arrays are found at startup by probing one instance of each. A check
such as <code>napi_is_date</code> is therefore exact: an object whose prototype is
<code>Date.prototype</code> is not a Date, and a Date from another realm is one.</li>
<li><strong>Accessors are captured.</strong> The <code>DataView</code> and <code>%TypedArray%</code> getters,
<code>Date.prototype.getTime</code> and the <code>ArrayBuffer</code> / <code>DataView</code> constructors are
captured before any user code runs: patching the globals has no effect.</li>
<li><strong>Pointers into buffers stay valid while the buffer is alive and not
detached.</strong> QuickJS never moves ArrayBuffer memory, but resizing a
resizable ArrayBuffer may reallocate it: read <code>data</code> again after JavaScript
ran.</li>
</ul>
<pre class="mermaid">flowchart LR
    AB["ArrayBuffer&#x3C;br/>(or SharedArrayBuffer)"] --> TA["TypedArray&#x3C;br/>type, byte_offset, length"]
    AB --> DV["DataView&#x3C;br/>byte_offset, byte_length"]
    AB --> BUF["Buffer&#x3C;br/>(Uint8Array subclass,&#x3C;br/>see node-specific.md)"]
    TA -. "data = buffer data + byte_offset" .-> AB
</pre>

<h2 id="arraybuffer"><a class="heading-anchor" href="#arraybuffer">ArrayBuffer</a></h2>
<h3 id="napi_create_arraybuffer"><a class="heading-anchor" href="#napi_create_arraybuffer"><code>napi_create_arraybuffer</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_create_arraybuffer</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">size_t</span><span style="color:#E36209;--shiki-dark:#FFAB70"> byte_length</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">                                    void</span><span style="color:#D73A49;--shiki-dark:#F97583"> **</span><span style="color:#E36209;--shiki-dark:#FFAB70">data</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_value </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">result</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Creates a <strong>zero-filled</strong> ArrayBuffer of <code>byte_length</code> bytes (through the
<code>ArrayBuffer</code> constructor, so QuickJS's size limits apply: too large a size
throws a <code>RangeError</code>, <code>napi_pending_exception</code>). <code>data</code> (optional) receives
a pointer to the contents, <code>NULL</code> for a zero-length buffer.</p>
<h3 id="napi_create_external_arraybuffer"><a class="heading-anchor" href="#napi_create_external_arraybuffer"><code>napi_create_external_arraybuffer</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_create_external_arraybuffer</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">    napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">void</span><span style="color:#D73A49;--shiki-dark:#F97583"> *</span><span style="color:#E36209;--shiki-dark:#FFAB70">external_data</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">size_t</span><span style="color:#E36209;--shiki-dark:#FFAB70"> byte_length</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">    node_api_basic_finalize </span><span style="color:#E36209;--shiki-dark:#FFAB70">finalize_cb</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">void</span><span style="color:#D73A49;--shiki-dark:#F97583"> *</span><span style="color:#E36209;--shiki-dark:#FFAB70">finalize_hint</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">    napi_value </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">result</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Creates an ArrayBuffer over memory owned by the addon. The memory is <strong>used in
place</strong>, never copied nor freed by QuickJS. When the ArrayBuffer is collected,
<code>finalize_cb(env, external_data, finalize_hint)</code> runs (queued, from the
event loop, as in Node.js), and the addon frees the memory there.</p>
<p><code>external_data == NULL</code> creates a buffer that reads as <strong>detached</strong> (V8 has
no backing store for <code>NULL</code> data).</p>
<h3 id="napi_is_arraybuffer"><a class="heading-anchor" href="#napi_is_arraybuffer"><code>napi_is_arraybuffer</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_is_arraybuffer</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_value </span><span style="color:#E36209;--shiki-dark:#FFAB70">value</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">bool</span><span style="color:#D73A49;--shiki-dark:#F97583"> *</span><span style="color:#E36209;--shiki-dark:#FFAB70">result</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p><code>true</code> for an <code>ArrayBuffer</code> (detached ones included). <code>false</code> for a
<code>SharedArrayBuffer</code>, as in V8.</p>
<h3 id="napi_get_arraybuffer_info"><a class="heading-anchor" href="#napi_get_arraybuffer_info"><code>napi_get_arraybuffer_info</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_get_arraybuffer_info</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_value </span><span style="color:#E36209;--shiki-dark:#FFAB70">arraybuffer</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>

<p>Stores the contents pointer and size; both outputs are optional. Accepts an
<code>ArrayBuffer</code> or, like Node.js 22.23, a <code>SharedArrayBuffer</code>

<h3 id="napi_detach_arraybuffer"><a class="heading-anchor" href="#napi_detach_arraybuffer"><code>napi_detach_arraybuffer</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_detach_arraybuffer</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_value </span><span style="color:#E36209;--shiki-dark:#FFAB70">arraybuffer</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Detaches an ArrayBuffer, as <code>structuredClone(ab, {transfer: [ab]})</code> would:
its length becomes 0 and every view on it reads as empty.
<code>napi_arraybuffer_expected</code> for anything other than an <code>ArrayBuffer</code> (every
non-shared QuickJS ArrayBuffer is detachable). Detaching an external buffer
does not run its finalizer early; the finalizer still runs when the object is
collected.</p>

<h2 id="typedarray"><a class="heading-anchor" href="#typedarray">TypedArray</a></h2>

<h2 id="promise"><a class="heading-anchor" href="#promise">Promise</a></h2>
<p>A <code>napi_deferred</code> is the pair of resolving functions of a new promise. It is
<strong>released by the first resolve or reject</strong>; deferreds never concluded are
freed at teardown.</p>
