<h2 id="when-to-use-them"><a class="heading-anchor" href="#when-to-use-them">When to use them</a></h2>
<p>Every <code>napi_value</code> keeps its JavaScript value alive until the scope it was
created in is closed. Each native entry point (a function call, module init, a
finalizer, a loop callback) already runs in an implicit scope, closed when it
returns. Explicit scopes are needed only when one call creates <strong>many
temporary values</strong>, typically in a loop:</p>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">for</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> (</span><span style="color:#D73A49;--shiki-dark:#F97583">uint32_t</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> i </span><span style="color:#D73A49;--shiki-dark:#F97583">=</span><span style="color:#005CC5;--shiki-dark:#79B8FF"> 0</span><span style="color:#24292E;--shiki-dark:#E1E4E8">; i </span><span style="color:#D73A49;--shiki-dark:#F97583">&#x3C;</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> n; i</span><span style="color:#D73A49;--shiki-dark:#F97583">++</span><span style="color:#24292E;--shiki-dark:#E1E4E8">) {</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">  napi_handle_scope scope;</span></span>
<span class="line"><span style="color:#6F42C1;--shiki-dark:#B392F0">  napi_open_handle_scope</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(env, </span><span style="color:#D73A49;--shiki-dark:#F97583">&#x26;</span><span style="color:#24292E;--shiki-dark:#E1E4E8">scope);</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">  napi_value item;</span></span>
<span class="line"><span style="color:#6F42C1;--shiki-dark:#B392F0">  napi_get_element</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(env, array, i, </span><span style="color:#D73A49;--shiki-dark:#F97583">&#x26;</span><span style="color:#24292E;--shiki-dark:#E1E4E8">item);</span><span style="color:#6A737D;--shiki-dark:#6A737D">   /* released at close */</span></span>
<span class="line"><span style="color:#6A737D;--shiki-dark:#6A737D">  /* ... */</span></span>
<span class="line"><span style="color:#6F42C1;--shiki-dark:#B392F0">  napi_close_handle_scope</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(env, scope);</span></span>

<p>Without the inner scope, a loop over a million elements keeps a million
values alive until the callback returns.</p>

<p>Rules:</p>
<ul>
<li>Scopes are <strong>strictly nested</strong>: close them in reverse order of opening.
Closing a scope that is not the innermost one returns
<code>napi_handle_scope_mismatch</code> and closes nothing.</li>
<li>A <code>napi_value</code> from a closed scope must not be used.</li>
<li>Close every scope you open before returning. A scope left open by a
function called from JavaScript is closed automatically with the call's
implicit scope (Debug builds print a warning). A scope left open by a
callback entered from the event loop (async work <code>complete</code>, a thread-safe
function's <code>call_js_cb</code>) or by a finalizer is a <strong>fatal error</strong> ("a callback
left a handle scope open", "a finalizer left a handle scope open"), as in
Node.js.</li>
<li>Opening a scope does not allocate in the steady state: scope records are
recycled.</li>
</ul>

<h3 id="napi_open_handle_scope"><a class="heading-anchor" href="#napi_open_handle_scope"><code>napi_open_handle_scope</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_open_handle_scope</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_handle_scope </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">result</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Opens a scope nested in the current one. Values created afterwards belong to
it.</p>
<h3 id="napi_close_handle_scope"><a class="heading-anchor" href="#napi_close_handle_scope"><code>napi_close_handle_scope</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_close_handle_scope</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_handle_scope </span><span style="color:#E36209;--shiki-dark:#FFAB70">scope</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Closes <code>scope</code>, releasing every value created since it was opened.</p>
<ul>
<li><code>napi_handle_scope_mismatch</code>: no user scope is open, or <code>scope</code> is not the
innermost one.</li>
<li><code>napi_invalid_arg</code>: <code>scope</code> is not a handle scope (for example an escapable
scope, which needs <code>napi_close_escapable_handle_scope</code>).</li>
</ul>
<h3 id="napi_open_escapable_handle_scope"><a class="heading-anchor" href="#napi_open_escapable_handle_scope"><code>napi_open_escapable_handle_scope</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_open_escapable_handle_scope</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">    napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_escapable_handle_scope </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">result</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Opens a scope from which one value can be escaped. A slot is reserved in the
<strong>parent</strong> scope before the new scope starts, so the escaped value belongs to
the parent.</p>
<h3 id="napi_close_escapable_handle_scope"><a class="heading-anchor" href="#napi_close_escapable_handle_scope"><code>napi_close_escapable_handle_scope</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_close_escapable_handle_scope</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">    napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_escapable_handle_scope </span><span style="color:#E36209;--shiki-dark:#FFAB70">scope</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Closes an escapable scope, with the same rules as <code>napi_close_handle_scope</code>.</p>
