<h2 id="the-callback"><a class="heading-anchor" href="#the-callback">The callback</a></h2>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">typedef</span><span style="color:#6F42C1;--shiki-dark:#B392F0"> napi_value</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> (</span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">napi_callback</span><span style="color:#24292E;--shiki-dark:#E1E4E8">)(napi_env env, napi_callback_info info);</span></span></code></pre>
<p>A native function receives the env and an opaque <code>info</code>, valid only during
the call. It returns the result, or <code>NULL</code> for <code>undefined</code>. If it leaves an
exception pending (<code>napi_throw*</code>, or a failed call into JavaScript), the
returned value is ignored and the exception propagates to the caller.</p>
<p>Every call runs in its own handle scope: values created during the call are
released when it returns, except the returned one. The last error is cleared
before the callback runs.</p>
<hr>
<h3 id="napi_create_function"><a class="heading-anchor" href="#napi_create_function"><code>napi_create_function</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_create_function</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">const</span><span style="color:#D73A49;--shiki-dark:#F97583"> char</span><span style="color:#D73A49;--shiki-dark:#F97583"> *</span><span style="color:#E36209;--shiki-dark:#FFAB70">utf8name</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">                                 size_t</span><span style="color:#E36209;--shiki-dark:#FFAB70"> length</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_callback </span><span style="color:#E36209;--shiki-dark:#FFAB70">cb</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">void</span><span style="color:#D73A49;--shiki-dark:#F97583"> *</span><span style="color:#E36209;--shiki-dark:#FFAB70">data</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">                                 napi_value </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">result</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Creates a JavaScript function that calls <code>cb</code>. <code>data</code> is handed back by
<code>napi_get_cb_info</code>.</p>
<ul>
<li><code>utf8name</code> (optional; <code>NULL</code> gives <code>""</code>) becomes the <code>name</code> property;
<code>length</code> is its length in bytes or <code>NAPI_AUTO_LENGTH</code>.</li>
<li>Like a V8 function created by <code>Function::New</code>: own properties <code>length</code> (0)
and <code>name</code>, both non-writable, non-enumerable and configurable, in that
order; and an own <code>prototype</code> object whose <code>constructor</code> points back to the
function, so the function can also be called with <code>new</code>.</li>
<li>The function holds <code>data</code> as a plain pointer. To free it when the function is
collected, attach a finalizer with
<a href="/projects/quickjs-napi/docs/node-api/lifetime/#napi_add_finalizer"><code>napi_add_finalizer</code></a>.</li>
</ul>
<h3 id="napi_get_cb_info"><a class="heading-anchor" href="#napi_get_cb_info"><code>napi_get_cb_info</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_get_cb_info</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_callback_info </span><span style="color:#E36209;--shiki-dark:#FFAB70">cbinfo</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">                             size_t</span><span style="color:#D73A49;--shiki-dark:#F97583"> *</span><span style="color:#E36209;--shiki-dark:#FFAB70">argc</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_value </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">argv</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">                             napi_value </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">this_arg</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">void</span><span style="color:#D73A49;--shiki-dark:#F97583"> **</span><span style="color:#E36209;--shiki-dark:#FFAB70">data</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Reads the current call. Every output is optional:</p>
<ul>
<li><code>argc</code> is in/out: on input the capacity of <code>argv</code>, on output the <strong>actual</strong>
number of arguments, which may be larger than the capacity.</li>
<li><code>argv</code> receives <code>min(capacity, actual)</code> arguments; the remaining slots up to
the capacity are filled with <code>undefined</code>. <code>argc</code> is required when <code>argv</code> is
given.</li>
<li><code>this_arg</code> receives the receiver. In a construct call this is the new object
created from <code>new.target.prototype</code>.</li>
<li><code>data</code> receives the pointer given to <code>napi_create_function</code>,
<code>napi_define_class</code> or the property descriptor.</li>
</ul>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">size_t</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> argc </span><span style="color:#D73A49;--shiki-dark:#F97583">=</span><span style="color:#005CC5;--shiki-dark:#79B8FF"> 3</span><span style="color:#24292E;--shiki-dark:#E1E4E8">;</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_value </span><span style="color:#E36209;--shiki-dark:#FFAB70">argv</span><span style="color:#24292E;--shiki-dark:#E1E4E8">[</span><span style="color:#005CC5;--shiki-dark:#79B8FF">3</span><span style="color:#24292E;--shiki-dark:#E1E4E8">];</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_value self;</span></span>
<span class="line"><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_get_cb_info</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(env, info, </span><span style="color:#D73A49;--shiki-dark:#F97583">&#x26;</span><span style="color:#E36209;--shiki-dark:#FFAB70">argc</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, argv, </span><span style="color:#D73A49;--shiki-dark:#F97583">&#x26;</span><span style="color:#E36209;--shiki-dark:#FFAB70">self</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#005CC5;--shiki-dark:#79B8FF">NULL</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span>
<span class="line"><span style="color:#6A737D;--shiki-dark:#6A737D">/* argc may now be 0..N; argv[argc..2] are undefined */</span></span></code></pre>
<h3 id="napi_get_new_target"><a class="heading-anchor" href="#napi_get_new_target"><code>napi_get_new_target</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_get_new_target</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_callback_info </span><span style="color:#E36209;--shiki-dark:#FFAB70">cbinfo</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">                                napi_value </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">result</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Stores <code>new.target</code>: the constructor <code>new</code> was applied to (a subclass when
called through <code>super()</code>), or <code>NULL</code> when the function was called without
<code>new</code>. This is how a constructor detects a plain call.</p>
<h3 id="napi_call_function"><a class="heading-anchor" href="#napi_call_function"><code>napi_call_function</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_call_function</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_value </span><span style="color:#E36209;--shiki-dark:#FFAB70">recv</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_value </span><span style="color:#E36209;--shiki-dark:#FFAB70">func</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">                               size_t</span><span style="color:#E36209;--shiki-dark:#FFAB70"> argc</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">const</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> napi_value </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">argv</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">                               napi_value </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">result</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Calls <code>func</code> with <code>this = recv</code> and <code>argc</code> arguments. <code>recv</code> is required (use
<code>napi_get_undefined</code> or <code>napi_get_global</code>). <code>result</code> is optional.</p>
<ul>
<li><code>func</code> not a function: <code>napi_invalid_arg</code>, as in Node.js.</li>
<li>The function throws: <code>napi_pending_exception</code>, exception pending.</li>
<li>Up to 8 arguments are passed without allocation.</li>
</ul>

<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_new_instance</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_value </span><span style="color:#E36209;--shiki-dark:#FFAB70">constructor</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">                              size_t</span><span style="color:#E36209;--shiki-dark:#FFAB70"> argc</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">const</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> napi_value </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">argv</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">                              napi_value </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">result</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p><code>new constructor(...argv)</code>. <code>napi_invalid_arg</code> when <code>constructor</code> is not a
function; <code>napi_pending_exception</code> when it is not a constructor (an arrow
function, a method) or throws.</p>
<h3 id="napi_define_class"><a class="heading-anchor" href="#napi_define_class"><code>napi_define_class</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_define_class</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">const</span><span style="color:#D73A49;--shiki-dark:#F97583"> char</span><span style="color:#D73A49;--shiki-dark:#F97583"> *</span><span style="color:#E36209;--shiki-dark:#FFAB70">utf8name</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">                              size_t</span><span style="color:#E36209;--shiki-dark:#FFAB70"> length</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_callback </span><span style="color:#E36209;--shiki-dark:#FFAB70">constructor</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">                              void</span><span style="color:#D73A49;--shiki-dark:#F97583"> *</span><span style="color:#E36209;--shiki-dark:#FFAB70">data</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">size_t</span><span style="color:#E36209;--shiki-dark:#FFAB70"> property_count</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">                              const</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> napi_property_descriptor </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">properties</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">                              napi_value </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">result</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Creates a constructor function named <code>utf8name</code> (required) that calls
<code>constructor</code>, then defines the properties:</p>
<ul>
<li>descriptors <strong>without</strong> <code>napi_static</code> go on <code>prototype</code> (instance methods,
accessors and values);</li>
<li>descriptors <strong>with</strong> <code>napi_static</code> go on the constructor itself.</li>
</ul>
<p>Descriptors follow <a href="/projects/quickjs-napi/docs/node-api/objects/#napi_define_properties"><code>napi_define_properties</code></a>.
As with V8's prototype templates, when two instance descriptors have the same
key <strong>the later one wins</strong>, whatever the attributes of the earlier one
(node-addon-api relies on it). Static descriptors are defined one by one, so
redefining a non-configurable static property fails, as in Node.js.</p>
<p>The usual pattern pairs the class with <a href="/projects/quickjs-napi/docs/node-api/lifetime/#napi_wrap"><code>napi_wrap</code></a>:</p>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">static</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> napi_value </span><span style="color:#6F42C1;--shiki-dark:#B392F0">Counter_New</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_callback_info </span><span style="color:#E36209;--shiki-dark:#FFAB70">info</span><span style="color:#24292E;--shiki-dark:#E1E4E8">) {</span></span>

<p><strong>Difference from Node.js:</strong> V8 attaches a <em>signature</em> to prototype methods,
so calling one on an object that was not created by the class throws
<code>TypeError: Illegal invocation</code> before the callback runs. In quickjs-napi the
callback runs and must validate <code>this</code> itself, as <code>Counter_Increment</code> does
above (<code>napi_unwrap</code> fails on objects that are not wrapped). See
<a href="/projects/quickjs-napi/docs/compatibility/">compatibility.md</a>.</p>
<h3 id="napi_run_script"><a class="heading-anchor" href="#napi_run_script"><code>napi_run_script</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_run_script</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_value </span><span style="color:#E36209;--shiki-dark:#FFAB70">script</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>

<p>Compiles and runs <code>script</code> (a string) as a classic global script in the
current context, like <code>v8::Script::Compile</code> + <code>Run</code>, and stores its
completion value. The file name in stack traces is <code>&#x3C;anonymous></code>.</p>
<ul>
<li><code>script</code> not a string: <code>napi_string_expected</code>.</li>
<li>A syntax error or an exception thrown by the script: <code>napi_generic_failure</code>,
<strong>with the exception pending</strong>, as in Node.js.</li>
