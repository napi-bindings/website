<h3 id="napi_create_async_work"><a class="heading-anchor" href="#napi_create_async_work"><code>napi_create_async_work</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_create_async_work</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_value </span><span style="color:#E36209;--shiki-dark:#FFAB70">async_resource</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">                                   napi_value </span><span style="color:#E36209;--shiki-dark:#FFAB70">async_resource_name</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">                                   napi_async_execute_callback </span><span style="color:#E36209;--shiki-dark:#FFAB70">execute</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">                                   napi_async_complete_callback </span><span style="color:#E36209;--shiki-dark:#FFAB70">complete</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">                                   void</span><span style="color:#D73A49;--shiki-dark:#F97583"> *</span><span style="color:#E36209;--shiki-dark:#FFAB70">data</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_async_work </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">result</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Creates a work item; nothing runs until it is queued. <code>execute</code> is required,
<code>complete</code> is optional. <code>async_resource</code> (optional; <code>null</code>/<code>undefined</code> give
<code>napi_object_expected</code>) and <code>async_resource_name</code> (required; a symbol gives
<code>napi_string_expected</code>) are only validated: there is no <code>async_hooks</code>.</p>
<p>The item belongs to the addon until <code>napi_delete_async_work</code>. Items never
deleted are freed at teardown.</p>
<h3 id="napi_queue_async_work"><a class="heading-anchor" href="#napi_queue_async_work"><code>napi_queue_async_work</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_queue_async_work</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(node_api_basic_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">                                  napi_async_work </span><span style="color:#E36209;--shiki-dark:#FFAB70">work</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Queues the item (<code>uv_queue_work</code>): <code>execute(env, data)</code> runs on a pool thread,
then <code>complete(env, status, data)</code> on the loop thread with <code>napi_ok</code>. The
queued item keeps the loop alive.</p>
<ul>
<li>Queuing an item that is already queued, or queuing while the host is being
destroyed, returns <code>napi_generic_failure</code>.</li>
<li>The item can be queued again once <code>complete</code> has started, including from
<code>complete</code> itself.</li>
</ul>
<h3 id="napi_cancel_async_work"><a class="heading-anchor" href="#napi_cancel_async_work"><code>napi_cancel_async_work</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_cancel_async_work</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(node_api_basic_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">                                   napi_async_work </span><span style="color:#E36209;--shiki-dark:#FFAB70">work</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Cancels a queued item whose <code>execute</code> has not started (<code>uv_cancel</code>).
<code>complete</code> then still runs, with status <code>napi_cancelled</code>. When <code>execute</code> is
already running or done, cancellation fails with <code>napi_generic_failure</code>.</p>
<h3 id="napi_delete_async_work"><a class="heading-anchor" href="#napi_delete_async_work"><code>napi_delete_async_work</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_delete_async_work</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_async_work </span><span style="color:#E36209;--shiki-dark:#FFAB70">work</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Frees the item. Usually called from <code>complete</code>. Deleting an item that is
still queued is undefined behaviour in Node.js; here the item is only marked,
and freed after its <code>complete</code> has run.</p>
<p>At teardown, queued items are cancelled, in-flight ones are waited for, and
their <code>complete</code> runs with JavaScript disabled, so the addon can still free
its data.</p>
<h2 id="thread-safe-functions"><a class="heading-anchor" href="#thread-safe-functions">Thread-safe functions</a></h2>
<p>A thread-safe function lets any thread schedule a call to JavaScript on the
loop thread. It is a port of Node 22's implementation: a queue protected by a
mutex, a <code>uv_async_t</code> to wake the loop thread, and up to 1000 calls dispatched
per wake-up. Its life cycle is shown in
<a href="/projects/quickjs-napi/docs/architecture/#thread-safe-functions">architecture.md</a>.</p>

<h3 id="exceptions-in-call_js_cb"><a class="heading-anchor" href="#exceptions-in-call_js_cb">Exceptions in <code>call_js_cb</code></a></h3>
<p>An exception left pending by <code>call_js_cb</code> (or <code>thread_finalize_cb</code>) has no
JavaScript caller. For modules built for <strong>Node-API ≥ 10</strong> it is reported as
uncaught (<code>process.on('uncaughtException')</code>). For older modules it is
dropped with a one-time <code>DEP0168</code> deprecation warning on stderr, as in
Node.js, unless the host forces the policy
(<code>--force-node-api-uncaught-exceptions-policy</code>, or
<a href="/projects/quickjs-napi/docs/embedding/#qjsnapi_host_set_force_uncaught_exceptions_policy"><code>qjsnapi_host_set_force_uncaught_exceptions_policy</code></a>).</p>
<p>Exceptions from async work <code>complete</code> callbacks and from finalizers are always
reported as uncaught.</p>
