<h2 id="when-finalizers-run"><a class="heading-anchor" href="#when-finalizers-run">When finalizers run</a></h2>
<p>Every finalizer in this file (<code>napi_wrap</code>, <code>napi_add_finalizer</code>,
<code>napi_create_external</code>, instance data) runs <strong>after</strong> its object is
collected, never synchronously and never inside the garbage collector:</p>
<pre class="mermaid">flowchart LR
    A["object unreachable"] --> B["QuickJS frees it&#x3C;br/>(refcount 0, or JS_RunGC for cycles)"]
    B --> C["holder finalizer:&#x3C;br/>finalizer queued on the env"]
    C --> D["next loop iteration (uv_check):&#x3C;br/>finalize_cb(env, data, hint)&#x3C;br/>in its own handle scope"]
    C --> E["or qjsnapi_host_destroy:&#x3C;br/>finalize_cb with JavaScript disabled"]
</pre>
<ul>
<li>A finalizer may call any Node-API function; JavaScript can run unless the
env is tearing down (<code>napi_cannot_run_js</code>, or <code>napi_pending_exception</code> for
modules built for Node-API &#x3C; 10).</li>
<li>An exception left pending by a finalizer is reported as uncaught.</li>
<li>Finalizers of objects still alive at teardown run during
<code>qjsnapi_host_destroy</code>: those with a finalizer first, newest first, then
plain references.</li>
<li>In the executable, <code>process.exit()</code> skips them, as in Node.js.</li>
</ul>
<p>Because QuickJS frees objects as soon as their last reference goes away,
finalizers usually run <strong>earlier</strong> than in Node.js (at the next loop
iteration instead of the next major GC). Objects in reference cycles are
collected by the cycle collector (<code>JS_RunGC</code>, or <code>gc()</code> in the executable).</p>
<hr>
<h2 id="references"><a class="heading-anchor" href="#references">References</a></h2>
<p>A <code>napi_ref</code> keeps a value reachable across calls. It has a count: above 0
the reference is <strong>strong</strong>; at 0 it is <strong>weak</strong> for objects, functions and
non-registered symbols (the value can be collected, and the reference then
reads as empty), and released for any other value.</p>
<h3 id="napi_create_reference"><a class="heading-anchor" href="#napi_create_reference"><code>napi_create_reference</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_create_reference</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_value </span><span style="color:#E36209;--shiki-dark:#FFAB70">value</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">                                  uint32_t</span><span style="color:#E36209;--shiki-dark:#FFAB70"> initial_refcount</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_ref </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">result</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Creates a reference with the given count.</p>
<ul>
<li>Modules built for <strong>Node-API ≥ 10</strong> may reference any value. Older modules
may only reference objects, functions and symbols (<code>napi_invalid_arg</code>
otherwise), as in Node.js.</li>
<li>With <code>initial_refcount == 0</code> and an object target, the reference is weak
from the start, but the object is kept alive until the end of the current
macrotask (<em>kept objects</em>), as V8 keeps it until the next GC.</li>
<li>A reference to a registered symbol (<code>Symbol.for</code>) is always strong; such
symbols are never collected anyway.</li>
</ul>
<p>The addon owns the reference and must delete it with
<code>napi_delete_reference</code>. References never deleted are freed at teardown.</p>
<h3 id="napi_delete_reference"><a class="heading-anchor" href="#napi_delete_reference"><code>napi_delete_reference</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_delete_reference</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(node_api_basic_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_ref </span><span style="color:#E36209;--shiki-dark:#FFAB70">ref</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Deletes the reference and releases its value (if still held). Must be called
exactly once per reference created by <code>napi_create_reference</code>, and by
<code>napi_wrap</code> / <code>napi_add_finalizer</code> when they returned one (see there). Can be
called from a finalizer.</p>
<h3 id="napi_reference_ref"><a class="heading-anchor" href="#napi_reference_ref"><code>napi_reference_ref</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_reference_ref</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_ref </span><span style="color:#E36209;--shiki-dark:#FFAB70">ref</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">uint32_t</span><span style="color:#D73A49;--shiki-dark:#F97583"> *</span><span style="color:#E36209;--shiki-dark:#FFAB70">result</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Increments the count and stores the new value in <code>result</code> (optional). Going
from 0 to 1 makes a weak reference strong again, if its target is still
alive.</p>
<h3 id="napi_reference_unref"><a class="heading-anchor" href="#napi_reference_unref"><code>napi_reference_unref</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_reference_unref</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_ref </span><span style="color:#E36209;--shiki-dark:#FFAB70">ref</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">                                 uint32_t</span><span style="color:#D73A49;--shiki-dark:#F97583"> *</span><span style="color:#E36209;--shiki-dark:#FFAB70">result</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Decrements the count and stores the new value in <code>result</code> (optional).
Reaching 0 makes the reference weak (or empty for primitives).
<code>napi_generic_failure</code> when the count is already 0.</p>
<h3 id="napi_get_reference_value"><a class="heading-anchor" href="#napi_get_reference_value"><code>napi_get_reference_value</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_get_reference_value</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_ref </span><span style="color:#E36209;--shiki-dark:#FFAB70">ref</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">                                     napi_value </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">result</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Stores the referenced value, or <code>NULL</code> when a weak reference's target has
been collected (or a primitive was released at count 0). Always check for

<h2 id="wrapping"><a class="heading-anchor" href="#wrapping">Wrapping</a></h2>
<p>Wrapping attaches a native pointer to a JavaScript object, typically the
<code>this</code> of a class constructor (see the
<a href="/projects/quickjs-napi/docs/node-api/functions/#napi_define_class"><code>napi_define_class</code> example</a>). The pointer is
stored in the object's <em>holder</em>, not in a property, so <strong>any object</strong> can be
wrapped: frozen objects, proxies and functions included, and wrapping is
invisible to JavaScript.</p>
<h3 id="napi_wrap"><a class="heading-anchor" href="#napi_wrap"><code>napi_wrap</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_wrap</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_value </span><span style="color:#E36209;--shiki-dark:#FFAB70">js_object</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">void</span><span style="color:#D73A49;--shiki-dark:#F97583"> *</span><span style="color:#E36209;--shiki-dark:#FFAB70">native_object</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">                      node_api_basic_finalize </span><span style="color:#E36209;--shiki-dark:#FFAB70">finalize_cb</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">                      void</span><span style="color:#D73A49;--shiki-dark:#F97583"> *</span><span style="color:#E36209;--shiki-dark:#FFAB70">finalize_hint</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_ref </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">result</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Associates <code>native_object</code> with <code>js_object</code> (which must be an object:
<code>napi_invalid_arg</code> otherwise). When the object is collected,
<code>finalize_cb(env, native_object, finalize_hint)</code> runs.</p>
<ul>
<li>Wrapping an object that is already wrapped returns <code>napi_invalid_arg</code>.</li>
<li><code>result</code> (optional) receives a weak reference (count 0) to the object. That
reference is <strong>owned by the addon</strong>: delete it from the finalizer, so
<code>finalize_cb</code> is then required. Without <code>result</code>, the library owns the
internal reference.</li>
</ul>
<h3 id="napi_unwrap"><a class="heading-anchor" href="#napi_unwrap"><code>napi_unwrap</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_unwrap</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_value </span><span style="color:#E36209;--shiki-dark:#FFAB70">js_object</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">void</span><span style="color:#D73A49;--shiki-dark:#F97583"> **</span><span style="color:#E36209;--shiki-dark:#FFAB70">result</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Stores the pointer given to <code>napi_wrap</code>. <code>napi_invalid_arg</code> when <code>js_object</code>
is not an object or is not wrapped: methods use this to validate <code>this</code>.</p>
<h3 id="napi_remove_wrap"><a class="heading-anchor" href="#napi_remove_wrap"><code>napi_remove_wrap</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_remove_wrap</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_value </span><span style="color:#E36209;--shiki-dark:#FFAB70">js_object</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">                             void</span><span style="color:#D73A49;--shiki-dark:#F97583"> **</span><span style="color:#E36209;--shiki-dark:#FFAB70">result</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Removes the wrap and stores the pointer in <code>result</code> (optional). <strong>The
finalizer will not run</strong>: the addon now owns the native object. If <code>napi_wrap</code>
returned a reference, the addon must still delete it. The object can then be
wrapped again.</p>
<h2 id="finalizers"><a class="heading-anchor" href="#finalizers">Finalizers</a></h2>
<h3 id="napi_add_finalizer"><a class="heading-anchor" href="#napi_add_finalizer"><code>napi_add_finalizer</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_add_finalizer</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_value </span><span style="color:#E36209;--shiki-dark:#FFAB70">js_object</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">                               void</span><span style="color:#D73A49;--shiki-dark:#F97583"> *</span><span style="color:#E36209;--shiki-dark:#FFAB70">finalize_data</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">                               node_api_basic_finalize </span><span style="color:#E36209;--shiki-dark:#FFAB70">finalize_cb</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">                               void</span><span style="color:#D73A49;--shiki-dark:#F97583"> *</span><span style="color:#E36209;--shiki-dark:#FFAB70">finalize_hint</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_ref </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">result</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Runs <code>finalize_cb(env, finalize_data, finalize_hint)</code> when <code>js_object</code> (an
object or a function) is collected. Unlike <code>napi_wrap</code>, an object may have
any number of finalizers, and nothing can be retrieved from it. <code>finalize_cb</code>
is required. <code>result</code> (optional) receives a weak reference owned by the addon,
to be deleted with <code>napi_delete_reference</code>; without it the library deletes the
reference after the finalizer runs.</p>
<p>A common use: free the <code>data</code> of a function created with
<code>napi_create_function</code>.</p>

<h2 id="type-tags"><a class="heading-anchor" href="#type-tags">Type tags</a></h2>
<p>A type tag is a 128-bit value (<code>napi_type_tag {uint64_t lower, upper}</code>)
attached to an object, so that an addon can check that an object it receives
really is one of its own before unwrapping it:</p>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">static</span><span style="color:#D73A49;--shiki-dark:#F97583"> const</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> napi_type_tag </span><span style="color:#005CC5;--shiki-dark:#79B8FF">kDatabaseTag</span><span style="color:#D73A49;--shiki-dark:#F97583"> =</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> {</span><span style="color:#D73A49;--shiki-dark:#F97583">0x</span><span style="color:#005CC5;--shiki-dark:#79B8FF">1edf75a38336451d</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">0x</span><span style="color:#005CC5;--shiki-dark:#79B8FF">a5ed9ce2e4c00c38</span><span style="color:#24292E;--shiki-dark:#E1E4E8">};</span></span>
<span class="line"><span style="color:#6A737D;--shiki-dark:#6A737D">/* when creating */</span></span>
<span class="line"><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_type_tag_object</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(env, obj, </span><span style="color:#D73A49;--shiki-dark:#F97583">&#x26;</span><span style="color:#E36209;--shiki-dark:#FFAB70">kDatabaseTag</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span>
<span class="line"><span style="color:#6A737D;--shiki-dark:#6A737D">/* when receiving */</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">bool</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> ok;</span></span>
<span class="line"><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_check_object_type_tag</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(env, arg, </span><span style="color:#D73A49;--shiki-dark:#F97583">&#x26;</span><span style="color:#E36209;--shiki-dark:#FFAB70">kDatabaseTag</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">&#x26;</span><span style="color:#E36209;--shiki-dark:#FFAB70">ok</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Like wraps, tags live in the object's holder (or inside the external), not in
a property.</p>
<h3 id="napi_type_tag_object"><a class="heading-anchor" href="#napi_type_tag_object"><code>napi_type_tag_object</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_type_tag_object</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(napi_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, napi_value </span><span style="color:#E36209;--shiki-dark:#FFAB70">value</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">                                 const</span><span style="color:#24292E;--shiki-dark:#E1E4E8"> napi_type_tag </span><span style="color:#D73A49;--shiki-dark:#F97583">*</span><span style="color:#E36209;--shiki-dark:#FFAB70">type_tag</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>

<code>napi_invalid_arg</code> if it already has a tag. <code>null</code> and <code>undefined</code> give
<code>napi_object_expected</code>.</p>

tag or none.</p>
<h2 id="instance-data"><a class="heading-anchor" href="#instance-data">Instance data</a></h2>
<p>Per-env data, the replacement for global variables in addons that can be
loaded several times (each load has its own env).</p>
<h3 id="napi_set_instance_data"><a class="heading-anchor" href="#napi_set_instance_data"><code>napi_set_instance_data</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_set_instance_data</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(node_api_basic_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">void</span><span style="color:#D73A49;--shiki-dark:#F97583"> *</span><span style="color:#E36209;--shiki-dark:#FFAB70">data</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">                                   napi_finalize </span><span style="color:#E36209;--shiki-dark:#FFAB70">finalize_cb</span><span style="color:#24292E;--shiki-dark:#E1E4E8">,</span></span>
<span class="line"><span style="color:#D73A49;--shiki-dark:#F97583">                                   void</span><span style="color:#D73A49;--shiki-dark:#F97583"> *</span><span style="color:#E36209;--shiki-dark:#FFAB70">finalize_hint</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Stores <code>data</code> on the env. <code>finalize_cb(env, data, finalize_hint)</code> (optional)
runs at teardown. Setting new data <strong>replaces</strong> the previous data without
finalizing it, as in Node.js.</p>
<h3 id="napi_get_instance_data"><a class="heading-anchor" href="#napi_get_instance_data"><code>napi_get_instance_data</code></a></h3>
<pre class="shiki shiki-themes github-light github-dark" style="background-color:#fff;--shiki-dark-bg:#24292e;color:#24292e;--shiki-dark:#e1e4e8" tabindex="0"><code><span class="line"><span style="color:#24292E;--shiki-dark:#E1E4E8">napi_status </span><span style="color:#6F42C1;--shiki-dark:#B392F0">napi_get_instance_data</span><span style="color:#24292E;--shiki-dark:#E1E4E8">(node_api_basic_env </span><span style="color:#E36209;--shiki-dark:#FFAB70">env</span><span style="color:#24292E;--shiki-dark:#E1E4E8">, </span><span style="color:#D73A49;--shiki-dark:#F97583">void</span><span style="color:#D73A49;--shiki-dark:#F97583"> **</span><span style="color:#E36209;--shiki-dark:#FFAB70">data</span><span style="color:#24292E;--shiki-dark:#E1E4E8">);</span></span></code></pre>
<p>Stores the data set by <code>napi_set_instance_data</code>, or <code>NULL</code>.</p>
