<p>Node-API implementation for <a href="https://bellard.org/quickjs/" target="_blank" rel="noreferrer noopener">QuickJS</a>
(2026-06-04, from <code>../quickjs-build</code>). Addons built for Node.js (node-gyp,
node-addon-api, napi-rs) are loaded <strong>unchanged</strong>: they resolve <code>napi_*</code> from
the <code>quickjs-napi</code> executable, exactly as they do from <code>node</code>.</p>

<h2 id="status"><a class="heading-anchor" href="#status">Status</a></h2>
<p>Milestone <strong>M6</strong> in progress (real-world conformance). Done: M1 values,
strings, objects, properties, functions, classes, errors; M2 references,
externals, wrapping, finalizers, type tags, instance data, <code>napi_run_script</code>;
M3 ArrayBuffer, TypedArray, DataView, BigInt, Date, Promise; M4 the
synchronous <code>node_api.h</code> (Buffer, async context, <code>napi_make_callback</code>,
callback scopes, <code>napi_fatal_exception</code>); M5 the libuv event loop (async
work, thread-safe functions, async cleanup hooks,
<code>napi_get_uv_event_loop</code>). See <code>PIANO-IMPLEMENTAZIONE.md</code> in the project for
the plan.</p>
<ul>
<li>All <strong>155 Node-API functions</strong> (version 10) are implemented.</li>
<li>They pass 30 tests of the Node.js <code>js-native-api</code> suite, 19 of its
<code>node-api</code> suite, and 78 of the 83 test modules of the <strong>node-addon-api
8.9.2</strong> suite in its four binding variants (the others need
<code>worker_threads</code>, <code>npm</code> or test the npm package itself).</li>
<li>Behaviour follows <strong>Node.js 22.23.4</strong>; the few differences are listed in
<a href="/projects/quickjs-napi/docs/compatibility/">compatibility.md</a>. <code>NAPI_EXPERIMENTAL</code> APIs are not
provided.</li>
</ul>
