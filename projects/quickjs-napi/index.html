quickjs-napi

0.0.x

A Node-API implementation for QuickJS: addons built for Node.js load unchanged, resolving napi_* from the quickjs-napi executable.

1 star0 forksv0.0.2· Nov 18, 2026Apache-2.0
Repository
OverviewDocs21Releases2Activity

Node-API implementation for QuickJS (2026-06-04, from ../quickjs-build). Addons built for Node.js (node-gyp, node-addon-api, napi-rs) are loaded unchanged: they resolve napi_* from the quickjs-napi executable, exactly as they do from node.

quickjs-napi -e "console.log(require('./build/Release/addon.node').hello())"

Status

Milestone M6 in progress (real-world conformance). Done: M1 values, strings, objects, properties, functions, classes, errors; M2 references, externals, wrapping, finalizers, type tags, instance data, napi_run_script; M3 ArrayBuffer, TypedArray, DataView, BigInt, Date, Promise; M4 the synchronous node_api.h (Buffer, async context, napi_make_callback, callback scopes, napi_fatal_exception); M5 the libuv event loop (async work, thread-safe functions, async cleanup hooks, napi_get_uv_event_loop). See PIANO-IMPLEMENTAZIONE.md in the project for the plan.

  • All 155 Node-API functions (version 10) are implemented.
  • They pass 30 tests of the Node.js js-native-api suite, 19 of its node-api suite, and 78 of the 83 test modules of the node-addon-api 8.9.2 suite in its four binding variants (the others need worker_threads, npm or test the npm package itself).
  • Behaviour follows Node.js 22.23.4; the few differences are listed in compatibility.md. NAPI_EXPERIMENTAL APIs are not provided.

Quick start

quickjs-build must be checked out next to this repository (../quickjs-build, branch feat/quickjs-2026-06-04).

cmake --preset unix-debug            # windows-zig-debug on Windows
cmake --build --preset unix-debug
ctest --preset unix-debug
quickjs-napi [options] script.js [args...]
quickjs-napi [options] -e <code> [args...]
