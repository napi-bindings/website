#include <node_api.h>

static napi_value Hello(napi_env env, napi_callback_info info) {
  napi_value result;
  napi_create_string_utf8(env, "world", NAPI_AUTO_LENGTH, &result);
  return result;
}

static napi_value Init(napi_env env, napi_value exports) {
  napi_property_descriptor desc = { "hello", 0, Hello, 0, 0, 0, napi_default, 0 };
  napi_define_properties(env, exports, 1, &desc);
  return exports;
}

Why Node-API

Node-API is the C interface for native addons maintained by the Node.js project. It isolates addons from the JavaScript engine underneath, so a compiled binary survives engine and Node.js upgrades.

ABI stable
An addon compiled once keeps loading in later major versions of Node.js, without recompilation.
Engine independent
js_native_api.h never exposes V8. The same API is implemented by Bun, Deno, Electron, QuickJS and more.
Any language
A plain C ABI: C++, Rust, Go, Zig, C# and Swift reach it through their foreign function interfaces.
