Node-API beyond C

Because Node-API is a plain C ABI, other languages can bind to it and other JavaScript runtimes can implement it. The lists below are synchronised with nodejs/abi-stable-node; napi-bindings projects are highlighted.

Build and distribution tools

Compile addons and ship prebuilt binaries.

Marmottanapi-bindings
Zig-based builds for C and C++ addons, no node-gyp or CMake required.
node-api-stubnapi-bindings
A CMake target that links addons on every platform without Node.js.
node-gyp
The default build tool, based on gyp-next and bundled with npm.
CMake.js
Builds addons with CMake; a good fit for projects that already use it.
node-pre-gyp
node-gyp plus upload of prebuilt binaries to a server of your choice.
prebuild
Builds with node-gyp or CMake.js and uploads binaries to GitHub releases.
prebuildify
Bundles prebuilt binaries inside the npm package itself.

From the Node.js project

Libraries, headers and examples maintained by the Node-API team.

node-addon-api
Header-only C++ wrapper maintained by the Node.js project.
node-addon-examples
Examples in C, node-addon-api and NAN, side by side.
node-api-headers
The Node-API headers and symbol lists, as an npm package.
