Node-API

Versions

Node-API versions are independent from Node.js versions. Each Node-API version adds functions; an addon declares the version it needs and runs on every Node.js release that supports it.

Since Node-API 9
Runtimes that support a version above 8 also support every version from 8 up, and default to 8. Define NAPI_VERSION to opt into newer behaviour and functions.
